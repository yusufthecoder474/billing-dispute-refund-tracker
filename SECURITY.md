# Security

Use fictional data and the local demo profile only for demonstrations. No real payment gateway is connected. See [security limitations](docs/SECURITY_LIMITATIONS.md) for authentication, authorization, CSRF and deployment boundaries.

If you discover a vulnerability, do not post passwords, real records or exploit dumps publicly. Report a minimal synthetic reproduction privately to the repository owner through a private contact channel they have actually published. This repository does not invent a security email address. Include the affected version, steps, expected/observed behavior and a suggested fix if available. Review dependencies before any public deployment.
